removed from this mirror. The game itself is a single self-contained HTML file
(WebGL + WebAudio, with all art and audio generated procedurally at runtime)
and makes no network requests; no online services were added here.

Supports keyboard/mouse and touch. One player versus nine AI heroes on a
three-lane map.
